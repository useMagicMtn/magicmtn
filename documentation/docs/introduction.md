MagicMtn provides inference and sandboxed compute for agents. Use MagicMtn Cloud for managed resources, or run the open source server on your own infrastructure with providers you choose.

## MagicMtn Cloud

Start managed agent workspaces, connect tools and repositories, and share resources with your team. MagicMtn operates the service and provisions the compute.

[Get started with MagicMtn Cloud](./cloud/index.md).

## Open source and self-hosting

Run MagicMtn on your developer machine or an internal host. Install providers for local runtimes or resources in your own infrastructure accounts, then use the CLI and Web UI to manage sandboxes.

[Get started with open source MagicMtn](./open-source/index.md).

## CLI

Install the same `magic` CLI for either deployment. Use it to create computers, run commands, manage images, and connect coding agents.

[Install the CLI](./cli-basics.md#install) or browse the [command reference](./cli-reference.md).

Find answers to common questions in the [FAQ](./faq.md).
