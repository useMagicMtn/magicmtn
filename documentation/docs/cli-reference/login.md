---
title: login
---

Sign in through your browser and save a CLI session on this computer:

```sh
magic login
```

Approve access in the browser, then return to your terminal. If the browser does not open, use the URL printed by the command.

| Flag | Required | Description |
| --- | --- | --- |
| `--client <CLIENT>` | No | Application requesting access: `cli` or `pi`. Defaults to `cli`. |
