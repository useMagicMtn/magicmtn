Install a coding agent in your MagicMtn workspace.

## install

Install Pi and its `/magic` extension:

```sh
magic agents install pi
```

Start Pi or run `/reload` to load the extension.

Install [OpenCode's MagicMtn integration](../coding-agents/opencode.md) with:

```sh
magic agents install opencode
```

Start or restart OpenCode to load the integration.
