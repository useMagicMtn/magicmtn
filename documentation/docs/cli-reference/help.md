---
title: help
---

Show help for a command or subcommand:

```sh
magic help
magic help computer
magic computer new --help
```

```sh
magic <command> [subcommand] [options]
```

Arguments in angle brackets are required. Arguments in square brackets are optional. Replace placeholders with your own values.

Run `magic` to list commands. Add `--help` to any command to see its arguments and options:

```sh
magic computer new --help
```

| Option | Description |
| --- | --- |
| `-h`, `--help` | Show help for a command. |
| `-V`, `--version` | Show the CLI version. Use with `magic`. |
